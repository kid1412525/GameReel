# GameReel

Windows 用の画面録画アプリです。画面全体や特定のウィンドウを、PC の音・マイクの音と一緒に録画します。
ゲームを起動すると自動で録画を始めたり、直前の場面だけをあとから保存したり（リプレイ）、録った動画をそのまま編集したりできます。
録画は、そのまま人に送れる MP4（H.264 + AAC）で保存されます。

## ダウンロード

最新版は [Releases](../../releases/latest) から `GameReel_Setup.exe` をダウンロードしてください。

## 主な機能

**録画**

- 画面全体・ウィンドウ・画面の一部（ドラッグで囲んだ範囲）を録画。画面全体は 60 コマ/秒
- PC の音は「PC 全体」「録っているアプリだけ」「選んだアプリだけ」から選べます。マイクも一緒に録れます
- 音の出どころ（アプリごと・マイク）を別々のトラックにも録るので、あとから音量を 1 つずつ変えられます
- 一時停止と再開、録画中のマーカー（しるし）、スクリーンショット
- どこからでも効くホットキー（ゲーム中でも効きます。キーは変えられます）
- 録画中は、音の大きさのバーと、実際に使っている容量を表示

**自動で録画・リプレイ**

- 決めておいたアプリ（ゲームなど）が起動したら自動で録画を始め、閉じたら止めて保存
- リプレイ：直前の 15 秒〜5 分を、キー 1 つであとから保存。保存したリプレイはクリップボードに入るので、そのまま Discord などに貼れます
- ウィンドウを閉じても通知領域で待機。Windows の起動時に立ち上げることもできます

**編集**

- いらない部分を切る、順番を入れ替える、ほかの録画をつなぐ
- 文字・画像・図形・ぼかし（モザイク）・音楽・効果音を入れる
- 速さを変える、逆再生、拡大、切り替え効果、縦長（9:16）や正方形での書き出し
- 字幕を声から自動で作る（日本語。英語に訳した字幕も作れます）
- 大きさを決めて保存（10 MB・25 MB など）、GIF・音だけの書き出し
- マーカーの前後だけを残す、音のないところを切る、ダイジェストやショート動画をまとめて作る

**そのほか**

- 古い録画の整理（日数・容量の上限）、消したくない録画の保護
- カメラも一緒に録って、編集で重ねる
- Stream Deck 用のプラグイン（録画の開始・停止、マーカー、リプレイの保存など）。インストールしたフォルダの `resources\app\streamdeck` にある `プラグインを入れる.bat` で入れます
- 録画や設定は、すべてお使いの PC の中に保存します。アカウントの登録や、外部への送信はありません

## 動作環境

- Windows 10 / 11（64 ビット）
- NVIDIA の GPU を積んだ Windows 11 の PC で動作を確認しています。AMD・Intel の GPU の PC では、まだ確認できていません（GPU が使えないときは CPU で録画します）

## インストール方法

1. [Releases](../../releases/latest) から `GameReel_Setup.exe` をダウンロードして実行します
2. 「Windows によって PC が保護されました」と出たときは、「詳細情報」→「実行」を押してください
   - 個人で作っている、署名のないアプリのために出る表示です
3. 画面の案内どおりに進めると、スタートメニューとデスクトップに「GameReel」のショートカットができます

- 管理者の権限は要りません（使っている人のところだけに入ります）
- 新しい版に入れ替えるときは、GameReel を終了してから（通知領域のアイコンを右クリック →「終了」）、新しい `GameReel_Setup.exe` を実行します。設定と録画はそのまま残ります

## 使い方

1. 録画したい画面かウィンドウを選びます
2. 「録画開始」を押します（または `Ctrl + Alt + Shift + R`）
3. もう一度押すと止まり、動画が保存されます（最初の保存先は「ビデオ」フォルダの中の `GameReel`）

止めたあとの画面から、ファイルのコピー（そのまま LINE・Discord・メールなどに貼れます）・編集・名前の変更などができます。

**どこからでも効くキー（最初の設定）**

| キー | すること |
| --- | --- |
| `Ctrl + Alt + Shift + R` | 録画の開始・停止 |
| `Ctrl + Alt + Shift + Space` | 録画の一時停止・再開 |
| `Ctrl + Alt + Shift + M` | 録画中に、マーカーを付ける |
| `Ctrl + Alt + Shift + S` | リプレイを保存する |
| `Ctrl + Alt + Shift + P` | スクリーンショットを撮る |

そのほかのキーは、アプリのウィンドウで `F1` を押すと一覧が出ます。

**ゲームを自動で録画するには**

1. 録りたいゲームを起動しておきます
2. 「設定」の「自動で録画」で、そのゲームにチェックを入れます
3. 次にそのゲームを起動したときから、録画が自動で始まります

「設定」の「待機」の 2 つ（ウィンドウを閉じても裏で待機する・Windows の起動時に立ち上げる）を入れておくと、何もしなくても録れるようになります。

## 知っておいてほしいこと

- PC の音は、PC の出力がミュート（音量 0）だと録れません（Windows の仕様です）
- 字幕を自動で作る機能は、最初に使うときに、聞き取り用のデータ（約 500 MB）をダウンロードします（ダウンロードの前に確認が出ます）
- ウィンドウを選んで録ると、コマ数は 45 コマ/秒ほどになります。ゲームは「画面全体」で録るのがおすすめです

## アンインストール

Windows の「設定」→「アプリ」→「インストールされているアプリ」の「GameReel」から「アンインストール」を選びます。
消えるのはアプリの本体とショートカットです。設定と、録画した動画は残ります。
